# 🌳 업무분장 탭

팔로 업무를 **회사 조직도처럼 한 화면에** 펼쳐 보는 2D 표. 대표가 고치고, 매니저와 공유 링크로 받은 사람은 보기만 한다. (2026-11-14 — 처음엔 3D 지도였는데 같은 날 2D 로 바꾸고, 입체 지도는 🧠 뇌 탭 `docs/brain/README.md` 으로 옮겼다)

## 한 줄 구조

`duty.js`(window.DUTY) 하나가 플래너 탭(`#dutyView`)과 공유 페이지(`duty-share.html`)를 같이 그린다. 내용은 DB `duty_nodes`(업무) · `duty_links`(연관), 처음 비어 있을 때만 `duty-seed.js` 기본값을 대표 화면에서 넣는다(그 뒤로는 DB 가 기준). 모양은 `duty.css` (뇌 탭도 이 파일의 화면 틀을 같이 쓴다).

## 화면

- **🏢 조직도**(첫 화면) — 맨 위 `팔로` → 영역 칸이 가로로 나란히 → 칸마다 업무. 업무 앞 동그라미 = 주담당(대·매·조·AI). 묶음(아래 업무가 있는 줄)은 접혀 있고 ▸ 로 펴거나 [▾ 세부 업무 펼치기]로 전부 편다. [⤢ 한 화면에 맞추기]는 전체가 칸 안에 들어오게 배율을 맞춘다(0.6~1.25배, 넓은 화면에서 기본 켜짐). 업무를 고르면 연관 업무에 노란 테두리.
- **📊 분장표** — 줄 = 업무, 칸 = 사람(역할). ● 주담당 ○ 함께. 이름 아래 숫자 = 주담당 업무 수 / 함께 맡는 것까지.
- **👥 사람별** — 사람(역할)마다 칸 하나, 맡은 일을 영역별로. ★ 주담당 ☆ 함께, 주기별 업무 수.
- **📋 자세히** — 설명까지 있는 업무분장표. `가지별` / `담당별`. 🖨 인쇄·PDF(새 창), ⬇ 엑셀(CSV).
- 업무를 누르면 오른쪽 칸이 열려 내용을 보고(대표는) 고친다. [📊 요약·점검]은 업무 수·담당별 업무량·빈 곳 점검을 연다.
- 거르기: 🙋 내 업무(내 역할·이름이 담당인 것) · 담당 · 주기 · 검색. 지금 거른 결과가 표·인쇄·CSV 에도 그대로. 조직도에서는 맞는 업무가 든 묶음이 저절로 펴진다.
- **🔎 점검**(요약·점검 칸): 담당 없는 업무 · 대신할 사람 안 정한 업무 · 주기 안 정한 업무 → 누르면 그것만.
- 폰: 조직도는 옆으로 밀어 보고, 업무를 고르면 위 절반 표 · 아래 절반 내용.

## 업무 한 개가 가진 것

이름 · 담당(쉼표로 여럿, **맨 앞이 주담당**) · 주기(매일·매주·매월·분기·수시) · 대신할 사람 · 설명 · 바로가기(플래너 탭 `#sales` 또는 https 주소) · 색 · 아래 가지 · 연관 업무.
담당은 글자 그대로라 역할(대표·매니저·조교·AI 자동화)도, 사람 이름도 된다(대표 화면에 `＋ 사람` 목록 = profiles 이름).

## 권한 (DB `supabase/migrations/20261114160000_duty.sql`)

| | 보기 | 고치기 |
|---|---|---|
| 대표 | 언제나 | 전부 |
| 매니저 | 대표가 **[매니저에게 공개]** 한 뒤 (`duty_meta.published`) | 못 함 |
| 조교 | 못 봄 | 못 함 |
| 공유 링크 | 키가 맞으면 (`duty_shared(p_token)`, 로그인 없음) | 못 함 |

- 처음엔 **초안**(대표만 보임, 탭 단추도 매니저에겐 안 보임). `DUTY.init()` 이 로그인 직후 공개 여부를 읽어 탭 단추를 켠다.
- 공유 링크는 공개 여부와 따로. 대표가 [공유 끄기]·[새 주소로 바꾸기] 하면 예전 주소는 바로 안 열린다(`duty_share` 한 줄).
- 자기 아래로 옮기기는 트리거(`duty_node_guard`)가 막는다. 가지를 지우면 아래 가지·연관 선도 같이(FK cascade).

## 점검

```
node --test tests/duty-seed.test.mjs          # 기본값: 제목 겹침·연관 이름표·주기/바로가기·탭 이름
bash ~/.cache/pallo-planner-dev/test-duty.sh  # 로컬 DB: 권한 23가지(공개 전·후, 매니저·조교·로그인 없음, 공유 키, 고리 막기)
```
화면은 체험판(`demo/index.html#duty`, 가짜 서버)이나 로컬(`localhost` → 로컬 Supabase)로 본다. 콘솔에서 `DUTY._dbg()`.

## 배포 순서

1. 마이그레이션: `supabase db query --linked --project-ref aiqrchgwrfrmscstlsmv -f supabase/migrations/20261114160000_duty.sql`
2. 프런트: `?v=`·`version.txt` 올리고 main 푸시 (duty-share.html 의 `?v=` 도 같이).
3. 대표가 탭을 처음 열면 기본 업무분장(업무 136개·연관 58개)이 들어간다 → 고친 뒤 [매니저에게 공개].

## 기본값을 다시 넣고 싶을 때

DB 가 비어 있어야 들어간다: `delete from duty_nodes;`(연관 선도 같이 지워짐) 뒤 대표가 탭을 연다. 고친 내용은 사라지니 CSV 로 먼저 내려받을 것.
