# 🔭 경쟁사 광고 정찰 + 소재 추천 (마케팅 탭 "경쟁사" 페이지)

2026-10-26 맥미니 세션에서 인터뷰(grill-me 방식)로 확정. 기존 메타 마케팅 시스템(`README.md`)과 **별개 기능**이지만 같은 마케팅 탭·같은 Supabase 안에 들어간다. 광고 계정에 손대지 않는다(집행은 대표가 광고관리자에서).

## 한 줄 정의

**맥미니가 매일 새벽 메타 광고 라이브러리에서 경쟁사 광고를 읽어 "새로 뜬 것·사라진 것·오래 도는 것"을 아침 리포트로 보여주고, 월요일엔 경쟁사 패턴 × 우리 등록 데이터를 교차해 소재 3~5개(아이디어·카피·복붙용 타겟값)를 추천한다.**

```
[매일 05:00 맥미니]                          [플래너 마케팅 탭 › 경쟁사]
광고 라이브러리(로그인 없음) ─▶ 스냅샷 ─▶ 어제와 비교 ─▶ 오늘의 변화 (신규·종료·장기 집행)
                                                      ├▶ 오래 도는 소재 랭킹
[월요일]                                               │
경쟁사 패턴 × mk_reports(우리 소재 판정) ─▶ 소재 추천 ─▶ 주간 추천 (아이디어·카피·타겟값)
                                                      └▶ 경쟁사 목록 (후보 켜고 끄기, 대표)
```

## 데이터 소스: 메타 광고 라이브러리 (웹)

2026-10-26 확인: `facebook.com/ads/library/?country=KR&active_status=active&q=영어회화` 를 **로그인 없이** 읽을 수 있었다(결과 ~1,000개). 라이브러리 **API는 한국 일반 광고를 주지 않으므로**(정치·사회 이슈 광고만) 브라우저로 읽는다.

카드마다 보이는 것(수집 필드):

| 필드 | 예 | 쓰임 |
|---|---|---|
| 라이브러리 ID | 2254476755408748 | 기본 키, 링크 `facebook.com/ads/library/?id=…` |
| 게재 시작일 | 2026. 8. 19. | **집행 일수** = 가장 중요한 간접 성과 신호 |
| 플랫폼 | FB·IG·메신저·오디언스 네트워크 | 게재위치 추천 근거 |
| 버전·사용 광고 수 | "여러 버전이 있는 광고", "광고 4개에서 이 크리에이티브 사용" | **투자 강도** |
| 페이지·제휴 | "unjena_ 페이지는 위버스마인드과 함께합니다" | 광고주 식별, 인플루언서 협업 여부 |
| 문구·제목·CTA·랜딩 도메인 | "지금 신청하기", KESSAM.COM | 훅·오퍼·CTA 분석 |
| 미디어 유형·길이 | 영상 0:49 / 이미지 / 캐러셀 | 포맷 분석 |

**보이지 않는 것:** 노출·클릭·리드·지출·타겟. 그래서 "잘 돌아간다"는 아래 규칙으로 **추정**하고 리포트에 "추정"이라고 적는다.

### "잘 돌아가는 광고" 판정 규칙

| 판정 | 조건 | 뜻 |
|---|---|---|
| 🟢 검증됨 | 활성 **14일 이상** | 돈 쓰며 유지 중 = 최소한 손해는 아님 |
| 🏆 핵심 소재 | 활성 **30일 이상** 또는 버전 여러 개 / 사용 광고 3개+ | 광고주가 밀고 있는 것 |
| 🆕 테스트 중 | 첫 발견 7일 이내 | 지켜보기 |
| ⚫ 종료 | 켜진 경쟁사 광고: 이틀 연속 안 보임 / 키워드로만 본 광고: 7일 안 보임 | 실패 또는 시즌 종료(개강 등). 단정하지 않음. 키워드 검색은 날마다 일부만 보여줘서(~1,000건 중 수십 건) 늦게 판정 |

한 광고주 안에서는 **같은 문구가 여러 ID로 뜨는 걸 묶어** 센다(위 예: 컬컴 송도점 동일 문구 2개 ID).

### 검색 세트 (그룹별)

- `en`: 영어회화, 영어학원, 성인영어, 대구 영어, 울산 영어, 구미 영어, 영어 스터디, 어학연수, 토익스피킹, 오픽 + 켜진 경쟁사 페이지명
- `jpcn`: 일본어회화, 일본어학원, 중국어회화, 중국어학원, 대구 일본어, 대구 중국어, JLPT, HSK + 켜진 경쟁사 페이지명
- 각 키워드 활성 광고 상위 N(노출순 정렬) + 켜진 경쟁사는 페이지 전체. 후보 발굴은 키워드 결과에 자주 보이는 페이지를 모아 올린다.

## 매일 흐름 (맥미니, 05:00)

1. 그룹별 검색 세트 + 켜진 경쟁사 페이지를 내장 브라우저로 읽어 카드 → `mkc_ads` upsert(`last_seen` 갱신). 새 ID는 작은 스크린샷(카드 영역, 가로 400px)을 Storage `mkc-thumbs/`에 저장.
2. 어제 스냅샷과 비교: 신규 / 종료(2일 연속 안 보이면) / 장기 집행 승격.
3. 아침 리포트(`mk_reports` kind=`competitor`, 그룹별 1건): 오늘의 변화 요약, 오래 도는 소재 TOP 10(판정·집행 일수·훅 한 줄·링크·썸네일), 새 광고에서 읽히는 흐름 한 줄.
4. 월요일 추가: 지난 7일 경쟁사 패턴(훅 유형·오퍼·포맷·CTA 빈도) × 우리 `mk_reports` weekly 판정 → **소재 추천 3~5개** (`mk_reports` kind=`creative`). 각 추천 = 근거(경쟁사 사례 링크 + 우리 잘 된 소재) · 형식(영상/이미지/캐러셀, 훅 3초) · 카피(기본문구·제목·설명·CTA) · 타겟값 블록(복붙용) · 촬영/제작 가이드 한 줄.
5. 실패(차단·로그인 요구·화면 변경) → 리포트에 "오늘 수집 실패(사유)" + 다음날 재시도. 몰래 어제 것으로 채우지 않음. 3일 연속 실패면 대표에게 알림.

타겟값 블록 형식(예):
```
연령 25~34 · 성별 전체 · 위치 대구 중구 반경 5km(동성로점)
관심사: 어학연수, 토익, 해외여행 · Advantage+ 오디언스 켬
게재위치: 인스타 릴스·스토리·피드 / 페북 릴스 · 일 예산 $8 · 목표: 잠재고객(인스턴트 양식)
```

## 플래너 "경쟁사" 페이지 (마케팅 탭 서브탭)

- **오늘**: 그룹 선택(매니저는 자기 그룹 고정) → 오늘의 변화 · 오래 도는 소재 랭킹(썸네일·판정·일수·링크) · 수집 상태.
- **주간 추천**: 월요일 추천 카드. 카피 복사 버튼, 타겟값 복사 버튼. 승인·게시 없음(광고는 대표가 직접).
- **경쟁사 목록**(대표만 편집): 상태 `candidate`(Claude가 올림) / `on` / `off`, 지역 태그, 라이브러리 페이지 링크 붙여넣기로 추가.
- 점검기 재사용: 추천 카피가 경쟁사 문구와 **유사도 높으면 경고**(베끼기 방지), 컬컴 언급 거부.

## 실행 환경 (맥미니)

- 수집·분석은 Claude Code 스킬 `pallo-competitor-ads`(신규) + 스크립트 `scripts/mkc/*.mjs`. 서비스 키는 기존 `~/.config/pallo/marketing.env`.
- 예약: 맥미니 예약 작업 매일 05:00(월요일은 추천 단계 포함). 잠자기 방지: `sudo pmset -a sleep 0 disksleep 0` + 디스플레이만 잠자기.
- 브라우저: 내장 브라우저(로그인 불필요). 요청 간 2~5초 간격, 하루 1회, 키워드 수 제한 → 차단 위험 최소화. 차단되면 간격을 늘리고 보고.
- 약관: 자동 수집은 메타 약관상 회색 지대. 공개 페이지를 하루 1회 낮은 빈도로 읽고 원본 미디어는 저장하지 않는 것으로 위험을 낮춘다. 대표가 이 점을 인지한 상태로 운영.

## 만드는 순서

| 단계 | 내용 | 확인 방법 |
|---|---|---|
| A | 테이블·Storage + 수집 스크립트(키워드 → 카드 파싱 → upsert) + 첫 수동 실행 | `en` 그룹 1회 수집, 카드 수·필드가 화면과 일치 |
| B | 후보 발굴 → 플래너 "경쟁사 목록" 페이지(켜고 끄기) → 대표가 선택 | 후보 20개쯤 올라오고 대표가 고름 |
| C | 매일 리포트(변화·랭킹) + 플래너 "오늘" 페이지 + 05:00 예약 | 3일 연속 자동 수집, 신규·종료 판정이 실제와 맞는지 |
| D | 월요일 소재 추천(경쟁사 × 우리 판정) + "주간 추천" 페이지 + 점검기 | 첫 추천 3~5개를 대표가 보고 "쓸 만하다" 판단, 1개 실제 집행 |

A·B 를 먼저 끝내고 대표가 경쟁사를 고른 뒤 C·D.

## 예외·보류

- 경쟁사 광고의 **성과 숫자는 영원히 모름** → 모든 판정에 "집행 기간 기준 추정" 문구.
- 지역 학원은 광고를 안 하는 곳이 많음 → 후보가 적으면 그룹 공통(온라인) 위주가 된다고 미리 적음.
- 경쟁사 오가닉 릴스는 범위 밖(기존 ③ 트렌드 스킬 몫).
- 광고 자동 집행·타겟 자동 세팅은 하지 않음. 나중에 원하면 메타 API 5단계 뒤에 별도 결정.

## 구현 (A단계, 2026-10-26)

- 계산: `mkc-core.js` (카드 글줄 → 필드, 판정, 종료 판단, 문구 묶기. 테스트 `node --test tests/mkc-core.test.mjs`)
