# ✍️ 블로그 작성기 (팔로플래너 "블로그" 탭)

사진만 올리거나 주제를 주면 네이버 블로그 시안(제목 5안·본문·해시태그)을 만들어 주는 탭.
2026-10-24 맥미니 세션에서 설계·1차 구현. 맥북에서 이어서 작업할 때 이 문서부터 읽기.

## 파일

| 파일 | 역할 |
|---|---|
| `blog.js` / `blog.css` | 탭 화면 (`window.BL`). sales.js 와 같은 방식으로 index.html 전역(sb·me·esc·toast…)을 씀 |
| `supabase/functions/blog-write/index.ts` | Edge Function. action: write · convert · style · keywords · similar · usage |
| `supabase/functions/blog-write/prompt.ts` | 시스템 프롬프트: 공통 규칙 + 스타일 프리셋 5개 + 옵션 문구 + 출력 JSON 스키마 |
| `supabase/migrations/20261024120000_blog.sql` | blog_profiles · blog_posts · blog_gens · blog_styles · blog_limits + RLS |

## 확정된 결정 (사용자와 grill-me로 정함)

- **발행은 복붙.** [📋 본문 복사] → 스마트에디터에 붙이면 `📷 사진 01` 자리표시가 남고, [🖼 사진 번호대로 받기]로 받은 01.jpg, 02.jpg…를 그 자리에 올린다. 사진까지 통째 복사(🧪)는 실험 기능 — 스마트에디터에서 실제로 되는지 확인 필요.
- **작성 모드 2개:** 사진 보고 쓰기 / 주제 주고 쓰기.
- **AI는 앱 안에서 바로** (Claude API, 모델 `claude-opus-5-5`, 키는 Edge Function 비밀값). 글 1편 대략 200~400원 추정.
- **키워드:** 네이버 검색광고 API(키워드 도구)로 월간 검색수·경쟁. 키 3개는 Supabase secrets로.
- **스타일:** 기본 프리셋 5개 + 매니저가 블로그 URL을 넣으면 구조·톤만 분석해 프리셋 추가(문장 복제 금지, 실명 대신 스타일 이름).
- **권한:** 지점 매니저는 자기 지점만, 대표(role=admin)는 전 지점 + 사용량. 지점당 하루 10회(대표가 사용량 탭에서 조정).
- **옵션:** 글쓴이(원장/강사/상담실장/수강생 후기형/ENFP 매니저) × 나이대, 타깃 독자(직장인/대학생·취준생/학부모/시니어/누구나) × 나이대, 어투, 컨셉.
- **1차 기능:** 발행 전 점검기, 제목 5안 + 대표 사진 문구, 사진 얼굴 자동 모자이크·자르기·밝기(기기 안에서만 처리), 인스타·당근·카톡 변환.
- **2차로 미룸:** 발행 캘린더(플래너 할 일 연동), 성과 기록(글 → 상담 → 매출 연결), 지점 사진 라이브러리.
- **기존 willyblog1 스킬에서 가져온 것:** 초안→편집장 비판→수정 루프(최대 2회), 해시태그 정렬(넓은 태그→핵심→롱테일→브랜드), **구 브랜드 "컬컴/CULCOM" 언급 금지(절대 규칙)**. ENFP 화자는 동성로점 기본 글쓴이. 사진 10~15장 강제는 뺌(네이버 공식: 사진 수는 순위와 무관).

## 지점 (4곳, 대상 = 성인 회화 중심)

| 지점 | 주소 | 과목 | 메모 |
|---|---|---|---|
| 대구동성로점 | 대구 중구 동성로2길 81, 5층 | 영어 + 스페인어 | 중앙로역·반월당역 도보권. 사람들은 "동성로"로 검색 |
| 대구일본어중국어점 | 대구 중구 동성로3길 83, 4층 | 일본어 + 중국어 | "대구 일본어학원"처럼 도시 단위로 검색 |
| 울산점 | 울산 남구 삼산중로 67, 7층 | 영어 + 일본어 + 스페인어 | 검색은 "삼산동", 법정동·플레이스는 "달동" → 글엔 삼산동 + 롯데·현대백화점 인근 |
| 구미점 | 경북 구미시 옥계북로 34, 7층 | 영어 + 일본어 | 2026-10 오픈 준비 중, 온라인 노출 0 → 오픈 소식·사전 상담 컨셉 |

공통 강점: 소수정예, 1:1 언어교환, 토스·토플·IELTS·오픽·JLPT(+HSK, DELE) 준비.
**팔로 대구 달서점은 다른 운영자** — 작성기 대상 아님, "대구 영어회화" 같은 넓은 키워드에선 경쟁자.

지점별 키워드 후보는 `blog.js` 의 `DEF` 에 들어 있다 (지점 설정 탭에서 저장하면 DB 값이 우선).

## 리서치 요약 (2026-10-24)

원본 보고서 2개(키워드 조사, 상위 블로그 분석)는 세션 임시 폴더에 있다가 지워졌다. 핵심은 아래와 코드(prompt.ts, blog.js DEF)에 남아 있다.

**키워드 (검색량 숫자는 확인 못 함 — 자동완성·검색결과 화면만 확인. 실제 수치는 검색광고 API로)**
- 메인 키워드("대구 일본어학원" 등)는 파워링크 10개 이상으로 경쟁이 세다 → 블로그는 동네 롱테일(동성로 영어회화 학원, 삼산동 일본어, 옥계동 영어회화, 대구 HSK 등) 먼저.
- 성인·직장인 조합(대구 성인영어회화, 울산 일본어 학원 직장인/주말, 구미 영어학원 성인반)이 자동완성에 많이 뜬다.
- "대구 언어교환", "울산 언어교환"이 뜬다 → 1:1 언어교환 강점과 직결, 경쟁 학원이 거의 안 씀.
- 스페인어는 오프라인 경쟁이 거의 없다(대구는 광고하는 학원 2곳 정도, 울산은 지역 학원 없음). "dele 시험 일정 2027" 같은 전국 정보성 글도 노릴 만함.
- JLPT 2026 시험일 7/5·12/6. 지금 검색하면 2027 일정이 위에 뜸 → 다음 해 일정 글은 미리.

**네이버 상위 노출 (네이버 검색 공식 블로그 18편 + 상위 글 43편 실측)**
- 랭킹: C-Rank(한 주제 꾸준히), D.I.A.+(직접 경험), 유사문서 필터. 2025-02부터 LLM 기반으로 자동 생성·가짜 경험 글을 더 잘 잡는다.
- 상위 글 중간값: 약 1,600자, 한 줄 21자 안팎, 사진 7장, 58%가 끝에 지도, 소제목은 인용구 블록, 거의 전부 존댓말, 제목 약 33자에 키워드 앞쪽.
- 공식적으로 "아니다": 사진 수는 순위와 무관, 링크 자체는 괜찮음(매 글 같은 링크 반복만 문제), "저품질 블로그"는 공식 개념 아님.
- **공식 스팸 정의 중 우리에게 위험한 것: 같은 틀로 지역명만 바꾼 글을 여러 지점에서 발행** → 지점 간 유사도 검사(similar action)를 넣은 이유.
- 법적: 대가성 후기 표기, 학원법상 과장 광고(등록 말소 사유 가능 — 각 지점 등록 형태는 확인 못 함, 법률 확인 필요).

## 남은 일

1. **환경:** 로컬 Supabase 개발 DB(맥북 `~/.cache/pallo-planner-dev`)에 마이그레이션 적용 → profiles/teams 실제 스키마와 RLS가 맞는지 확인 (blog_my_team / blog_is_admin 함수는 profiles(user_id, team_id, role) 가정).
2. **비밀값:** `supabase secrets set ANTHROPIC_API_KEY=… NAVER_AD_CUSTOMER_ID=… NAVER_AD_API_KEY=… NAVER_AD_SECRET=…` (채팅에 붙이지 말 것).
3. **배포:** `supabase functions deploy blog-write`, 마이그레이션 `supabase db push`, 프런트는 기존 방식대로(버전 문자열 `?v=` 와 version.txt 갱신 후 main 푸시).
4. **실제 테스트:** 글 생성 품질, 얼굴 모자이크(MediaPipe short-range는 교실 원거리 얼굴을 놓칠 수 있음 → 2×2 조각으로 보완했지만 확인 필요), 스마트에디터 붙여넣기(서식·🧪 통째 복사), 아이폰 사진 저장(공유 시트) 동작.
5. 맥북의 `keyword-map.md`·`strategy.md`(willyblog1 참조 파일)를 받아 동성로점 키워드 기본값에 반영.
